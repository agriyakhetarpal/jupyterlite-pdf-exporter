# `jupyterlite-pdf-exporter` playground

This folder contains example notebooks for trying out the [`jupyterlite-pdf-exporter`](https://github.com/agriyakhetarpal/jupyterlite-pdf-exporter) extension. Each notebook produces a different kind of output (plots, widgets, maps, tables, math, custom MIME renderers), so you can use them to check how that output comes out in the exported PDF.

To get started, open any notebook, such as [`matplotlib.ipynb`](matplotlib.ipynb), run the cells,
and use "File" > "Save and Export Notebook As" and select the PDF option to try it out!

## Notebooks

- [`matplotlib.ipynb`](matplotlib.ipynb) – static and interactive Matplotlib plots
- [`plotly.ipynb`](plotly.ipynb) – Plotly figures
- [`altair.ipynb`](altair.ipynb) – Altair/Vega-Lite charts
- [`folium.ipynb`](folium.ipynb) – an interactive `folium` map
- [`ipyleaflet.ipynb`](ipyleaflet.ipynb) – an interactive `ipyleaflet` map
- [`ipycanvas.ipynb`](ipycanvas.ipynb) – Conway's Game of Life on an `ipycanvas`
- [`interactive-widgets.ipynb`](interactive-widgets.ipynb) – `ipywidgets` controls
- [`renderers.ipynb`](renderers.ipynb) – custom MIME renderers (FASTA, GeoJSON, ...)
- [`python.ipynb`](python.ipynb) – a short introduction to the Pyodide-backed Python kernel
